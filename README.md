[![Live Demo](https://img.shields.io/badge/Live%20Demo-fundchain--livid.vercel.app-emerald?style=for-the-badge&logo=vercel)](https://fundchain-livid.vercel.app)

A production-ready, fully decentralized crowdfunding platform built on Ethereum. Campaign creators can raise ETH with a goal and deadline. Contributors can fund active campaigns and claim refunds if the goal is not met. Creators withdraw funds only on success.

---

## Features

- **Create Campaigns** — Set a funding goal (ETH) and duration (seconds)
- **Fund Campaigns** — Send ETH to any active campaign before its deadline
- **Withdraw** — Creator withdraws the full raised amount after a successful campaign
- **Refund** — Contributors reclaim their ETH if the campaign fails to meet its goal
- **Live UI** — Real-time progress bars, campaign status, deadlines, and contribution tracking
- **Wallet Integration** — MetaMask connect/disconnect, wrong-network detection and auto-switch
- **Security** — `ReentrancyGuard`, checks-effects-interactions, custom revert errors, no double-withdraw, no double-refund

## Setup

### Prerequisites

- Node.js `>=18`
- MetaMask browser extension
- An Alchemy or Infura account (for Sepolia)
- Sepolia testnet ETH ([faucet](https://sepoliafaucet.com))

### Install

```bash
# Clone the repo
git clone https://github.com/your-username/crowdfunding-dapp.git
cd crowdfunding-dapp

# Install backend dependencies
npm install

# Install frontend dependencies
cd frontend && npm install && cd ..
```

### Configure environment

Fill in `crowdfunding-dapp/.env`:

```env
SEPOLIA_RPC_URL=https://eth-sepolia.g.alchemy.com/v2/YOUR_KEY
PRIVATE_KEY=your_deployer_wallet_private_key
ETHERSCAN_API_KEY=your_etherscan_api_key
```

## Running Locally

```bash
# Terminal 1 — start local Hardhat node
npx hardhat node

# Terminal 2 — deploy to local node
npx hardhat run scripts/deploy.js --network localhost

# Terminal 3 — start frontend
cd frontend && npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and connect MetaMask to `localhost:8545` (Chain ID `31337`).

## Deployment to Sepolia

```bash
# Compile contracts
npx hardhat compile

# Deploy to Sepolia
npx hardhat run scripts/deploy.js --network sepolia
```

The deploy script automatically:
1. Deploys `Crowdfunding.sol` to Sepolia
2. Prints the contract address and transaction hash
3. Writes `address` + `abi` to `frontend/src/abi/Crowdfunding.json`

Update `frontend/.env.local`:

```env
NEXT_PUBLIC_CONTRACT_ADDRESS=0xYourDeployedContractAddress
NEXT_PUBLIC_CHAIN_ID=11155111
```

### Verify on Etherscan (optional)

```bash
npx hardhat verify --network sepolia 0xYourDeployedContractAddress
```

## Security Considerations

| Concern | Mitigation |
|---|---|
| **Reentrancy** | `ReentrancyGuard` on `fund`, `withdraw`, `refund` |
| **Checks-Effects-Interactions** | State updated before all external `.call{}()` transfers |
| **Double withdraw** | `withdrawn` boolean flag checked and set before transfer |
| **Double refund** | Contribution zeroed before transfer |
| **Post-deadline funding** | `block.timestamp >= deadline` check enforced on `fund` |
| **Unauthorized withdrawal** | `msg.sender == creator` enforced |
| **Goal not met withdrawal** | `totalRaised >= goal` enforced |
| **Custom errors** | Gas-efficient `revert CustomError()` instead of `require` strings |
| **Optimizer** | Solidity optimizer enabled (`runs: 200`) |
| **Private key** | Loaded via `.env`, never hardcoded — `.env` in `.gitignore` |
